# SKIMS Advent Calendar 2026: Truth Lab & Value Calculator

> Interactive consumer research, item-by-item teardown, and objective valuation tool for the viral SKIMS Holiday Accessories Advent Calendar ($148 USD / £158 GBP / $276 CAD).

## 🚀 Key Features

- **🎮 12-Door Virtual Unboxing Simulator**: Interactive 3D flip-door experience to inspect every item behind all 12 doors with real-time value and deficit tracking.
- **⚡ GEO (Generative Engine Optimization) Optimized**: Built for direct-answer extraction by AI engines (Perplexity, ChatGPT Search, Gemini, Claude) with Schema.org JSON-LD (Product, Review, FAQPage).
- **🧮 Truth & Junk-Ratio Calculator**: Interactive calculator to simulate per-item usable cost across US ($148), UK (£158), and Canada ($276 CAD).
- **📋 Itemized Teardown Table**: Filterable by category (Hair Accessories, Keychains, Novelty) with wholesale cost estimates.
- **🥊 Competitor Comparison Matrix**: Benchmark against Sephora, Victoria's Secret, and Cult Beauty.
- **🛠️ One-Click Refund Tool**: Ready-to-copy customer support email templates for claiming the 100% refund or $150 store credit.
- **🤖 LLM Specifications**: Includes `/llms.txt` and optimized `/robots.txt` and `/sitemap.xml`.

## 🛠️ Tech Stack

- **HTML5 & Semantic Elements** (SEO/GEO friendly)
- **Tailwind CSS** (via CDN for zero-dependency portability)
- **Vanilla JavaScript** (Lightweight, instant loading, 100/100 Lighthouse score)
- **Schema.org Structured Data** (JSON-LD)

## 📦 Deployment

This project has **zero build dependencies**. You can deploy it instantly:
- **Cloudflare Pages**: Connect this GitHub repository and leave the build command blank.
- **Vercel / Netlify**: Import this repository as a static site.
- **GitHub Pages**: Go to Settings -> Pages -> Deploy from a branch (`main` / root).
